# Brand reference and asset sources

Visual reference: [BookLeaf Publishing](https://www.bookleafpub.in/), reviewed on 17 October 2026. The portal adopts its coral/white palette, light pink background artwork, sans-serif type and rounded buttons. Smaller buttons use a darker coral for readable white text. Status badges retain distinct semantic colors.

The following files are downloaded from assets displayed on that homepage and served locally by Vite/Express:

The community images appear only as a homepage-inspired collage on the login page. They are not presented as photographs of the sample dataset's authors. The favicon is a code-drawn version of the square/slash brand motif. Existing book-cover illustrations remain decorative representations of the supplied sample titles.

Typography uses Avenir Next where available, with Nunito Sans and system sans-serif fallbacks. Public marketing claims and package prices were not copied into the support knowledge base; assignment policies and seeded account data are unchanged.
